# Practical Test: Front-end Developer

This was a practical test made by Mind the Graph company as a test for a frontend developer position. In the end i did not get the job but i liked the result

## How to run the project
1. `git clone https://github.com/Victor-Palha/Mind-the-Graph-Lading-Page.git`
2. `cd Mind-the-Graph-Lading-Page`
3. `npm install`
4. `npm run dev`

## Technologies
- React
- Tailwind CSS
